# 역할 7 — 반박 근거를 통한 최종 방향 종합

## 판정

**rev2 B / Orbital Observatory를 조건부 최종 방향으로 선택한다.** A의 구체·앞뒤 고리·명암이라는 물질 표현을 B의 큰 cropped 관측창 구도에 결합한다. 단순히 B를 추천한 사람이 더 많아서가 아니라, 초기 B에 제기된 실제 읽기영역 침범과 AOD 가림 문제가 수정됐고, 225px에서도 큰 곡률·구면 음영·고리 띠가 남기 때문이다.

이 문서는 정적 디자인 방향의 종합이며 아직 메인 스튜디오에 통합된 v4 모션을 승인하는 문서가 아니다. 통합·회귀·중단·Live tick 검증은 메인이 수행해야 한다. 계정 한도로 일부 역할의 최종 재검 보고가 없으므로 **7명 전원 최종 승인**이라고 쓰면 안 된다.

## 읽은 자료와 증거 상태

- `form.md`: 작은 입체 Cassini 안 A 추천, A가 축소에서 선 덩어리/배지가 되면 B로 바꿔야 한다는 반증 조건.
- `composition.md`: 오른쪽 화면 밖 큰 행성 B 추천, 보호영역·밝기·225px 반증 조건.
- `motion.md`: 정적 형태 교체를 우선하고, 고정 윤곽에서 짧은 재질 점등만 추가. A/B 교차 반박 포함.
- `visual-critic.md`: 초기 B의 실제 읽기영역 침범과 규칙적인 과밀 링을 차단 근거로 제시.
- `legibility.md`, `technical.md`: **파일 없음 / 미완**. 부모가 전달한 중간 메시지는 있었으나 최종 보고 파일이 있는 것처럼 간주하지 않았다.
- `gallery-round1.png`: 최초 후보.
- `gallery.png`, A/B/C SVG·PNG: rev2 후보. 직접 열어 비교했다.

역할 7은 rev2 A/B/C를 별도 Chromium 프로세스로 다시 렌더링해 아래 수치를 독립 측정했다. 기존 보고의 수치를 그대로 v4 재검 결과로 옮기지 않았다.

## 독립 측정 — rev2의 읽기영역

환경: Windows, Chromium headless 1243, 450×450 CSS px, 글꼴 로딩 후 PNG 캡처. 같은 SVG에서 `#cosmos`를 제거한 화면과 RGB 비교했다. 별·천체가 읽기영역의 배경을 바꾸는지 보는 검사이며, glyph 손상이나 실제 시선 측정을 뜻하지 않는다.

| 후보 | 시간 x100..344 / y194..270 | 날짜 x145..305 / y160..190 | 브랜드 x150..300 / y138..163 |
|---|---:|---:|---:|
| A | 변경 0 / 최대 채널차 0 | 0 / 0 | 131 / 65 |
| **B rev2** | **0 / 0** | **0 / 0** | **0 / 0** |
| C | 0 / 0 | 0 / 0 | 19 / 18 |

따라서 초기 B의 침범 수치를 수정 B의 현재 결함으로 재사용하면 안 된다. 반대로 보호 ROI가 0이라는 사실만으로 미학적 우수성을 증명할 수도 없다.

## 225px 실제 렌더 판단

A/B/C Active를 각각 225×225 CSS px로 직접 다시 렌더링했다.

- A: 구체와 전면 띠가 읽히며 v3 아이콘보다는 확실히 좋다. 다만 독립된 작은 물체가 드래곤 옆에 붙는 구조가 남고 브랜드 근처 링도 가까워 보인다.
- B rev2: 밝기를 낮춘 뒤에도 오른쪽의 큰 곡률·대기 띠·앞고리와 그림자가 남는다. 중앙 검정 영역은 분명하고 시간·드래곤이 먼저 읽힌다. 단순한 원주 이중 테두리만 남은 상태는 아니다.
- C: 선명하고 가볍지만 가장 큰 변화가 다시 원호이므로 사용자 요청에 가장 약하다.

이는 실제 렌더에 근거한 디자인 판단이며 사용자 선호 조사나 실기 가독성 결과는 아니다.

## AOD 측정

450px PNG에서 중심 `(224.5,224.5)`, 반지름 225 안의 RGB 중 하나라도 0보다 큰 픽셀을 셌다. 원형 표본은 159,068픽셀이다.

| 후보 | 비영 RGB 픽셀 | 비율 |
|---|---:|---:|
| A | 13,487 | 8.4788% |
| **B rev2** | **13,639** | **8.5743%** |
| C | 13,562 | 8.5259% |

모두 15% 디자인 참고값 아래지만 실제 소비전력·번인·공식 WFF 검사·심사 통과를 의미하지 않는다. 이 후보 수치는 메인 통합 후 최종 자산의 수치와 별개로 남겨야 한다.

## 최종 설계 계약

1. B의 현 보호 경계와 밝기를 유지한다. 물질을 더 잘 보이게 하려고 고리를 다시 x344 이하로 들이지 않는다.
2. 공식 Kali 드래곤 path, 고정 시각, 초록색 위계, INFINITY는 유지한다.
3. 구체·앞뒤 고리는 같은 기울기와 위치를 공유한다. 그림자·빛의 방향을 따로 돌리지 않는다.
4. AOD에서 채운 재질은 숨기고 같은 곡률과 가림 관계의 림·앞고리만 남긴다.
5. 복귀 모션은 재질 180–220ms, 앞 고리 40ms 지연+180ms 정도의 opacity로 한정한다. 전체 360ms를 늘리지 않는다.
6. 실제 최종 AOD·모션·mono 내보내기는 통합 후 재검한다.

## 남은 차단 조건과 추가 검증

- **정보 보호:** 동일 RGB 비교를 최종 450px SVG에서 반복. 시간·날짜·브랜드 ROI는 모두 0픽셀 변화를 목표로 한다. 225px도 직접 열어 본다.
- **AOD 가림:** 뒤 링이 몸체 위쪽 내부에 나타나지 않는지 불투명 구체와 전면 clip을 확인한다.
- **모션:** 0/90/180/360ms의 시간·행성 위치, 공통 DOM identity, 중간 반전 후 현재 opacity 연속성을 검사한다.
- **반복:** 20회 전환, 140ms 재생 예약 취소, 수동·OS 저감 모션, Live tick 중 노드·효과 유지를 재검한다.
- **정지 종료:** 자연 완료와 정적 renderer가 픽셀 단위로 일치해야 한다.
- **자산:** 공식 path 동일·mono 색 분리·서버 없이 SVG/PNG·중복 gradient/mask ID 간섭 여부를 검사한다.
- **실기 미확인:** 밝기·전력·WFF 지원·메모리·프레임 속도는 워치 확보 뒤 확인한다.

## 결론을 바꿀 조건

수정 B가 최종 케이스/225px/실기에서 단순한 어두운 수직 띠로만 읽히거나, 형상을 보여주기 위해 읽기 보호영역을 다시 침범해야 한다면 B를 기각하고 A를 조금 키운 대안으로 돌아간다. 현재 rev2 렌더에서는 이 조건이 발생하지 않아 B를 선택한다. 모든 검증이 끝난 것처럼 포장하지 않고 메인의 통합 검증을 다음 판단 단계로 남긴다.
