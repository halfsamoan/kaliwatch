7인 설계 토론 — Orbital Observatory

2026-10-25 / v4. 사용자의 “너무 구리고 간단하다”는 반려와 최소 7명 병렬 토론 요청을 기준으로 진행했다. 동시에 실행 가능한 수가 제한돼 설계 3명 → 비판 3명 → 종합 1명을 순차 병렬로 운영하고, 원 설계자 2명에게 재반박을 요청했다. 리드는 구현·실렌더·최종 판단을 맡았다.

참여자와 실제 수행 범위

역할 주장 또는 발견 기록 상태
1. 형태 설계 작은 Cassini A 추천. 구체·광원·뒤/앞 고리가 핵심 1차와 2차 완료. 실제 225px 비교 후 B로 추천 변경
2. 구도 설계 화면 밖 큰 행성 B 추천. 정보 영역을 보호해야 함 1차와 2차 완료. 고리/몸체 마스크 분리 재반박
3. 모션 설계 정적 재질을 먼저 개선하고 짧게 점등. 회전·비행 반대 직접 기존 0/90/180/360ms 확인, A/B 교차 반박 완료
4. 시각 Critic 최초 B는 읽기 영역 침범·과밀 패턴으로 차단 최초 실제 렌더·ROI 보고 완료. 후속 회차는 계정 한도 중단
5. 가독성/AOD Critic B 공간감 인정하되 작은 화면·밝기·정보 영역 반박 3안 225/450px 측정 및 중간 보고. 최종 별도 문서 미완
6. 기술 Verifier AOD 검은 몸체의 opacity 때문에 뒤 링 투과 발견 최초 부분 보고 후 중단. 새 회차에서 최종 21개 검증 완료
7. 종합 판단 수정 B를 독립 렌더·ROI 측정 후 조건부 선택 정적 방향 종합 완료. 통합 모션의 최종 승인은 별도라고 명시

실제로 7명이 참여했지만 7명 전원 최종 승인으로 포장하지 않는다. 계정 한도 때문에 일부 중간 회차가 중단된 사실과 미생성 문서를 구분한다. 최종 제품 검증은 리드 81개와 독립 기술 담당 21개다. 이는 102개 서로 다른 제품 기능이라는 의미가 아니다.

후보와 1차 반박

후보 의도 결정적 반박
A · Sculpted Cassini 작은 행성의 구체·고리·그림자를 정교하게 입체감은 좋아도 용 옆 배지 구도. 브랜드 주변 밀착
B · Orbital Observatory 원형 화면을 거대한 우주를 보는 관측창으로 처음에는 밝은 고리가 시간·날짜 영역을 침범하고 용과 경쟁
C · Eclipse Aperture 중력장 같은 정밀 선형 표현 다시 선 위주라 사용자가 반려한 단순함을 반복할 위험

형태 담당의 최초 A 제안은 r32였다. 메인 비교 렌더에서는 225px 인지를 위해 r40으로 시험했다. B는 중심 (458,102), 반지름 126의 일부만 보이게 했다. 구체·띠·그림자가 남는지와 시간 읽기를 실제 450/225px에서 비교했다.

무엇이 결론을 바꿨나

주장 반박·근거 반영
큰 B가 가장 풍부하다 최초 렌더에서 시간 ROI 변화 1,745px/max137, 날짜·브랜드도 침범. 배경 변화이며 글자를 지웠다는 주장은 아님 고리 감쇠 345→372, 재질 .78→.59
세부 선을 많이 넣으면 고급스럽다 72개 반복 링이 지문·격자처럼 보임 3개 주 면 띠 + 분리 틈 + 18개 미세 선. 표면 띠 대비 감소
AOD는 검은 구체를 흐리게 두면 된다 구체 전체 opacity .45가 뒤 링을 투과시킴. 기술 담당이 픽셀 재현 fill은 완전 불투명 black, stroke-opacity만 .45
위 수정이면 B 완료 구도 담당이 “전역 감쇠가 실제 limb까지 없애 줄무늬 패널이 된다”고 재반박 몸체·림 320→338, 고리 345→372로 마스크 분리
A는 작아서 재질이 모두 소실된다 형태 담당은 실제 225px에서 A도 구체 인지가 된다고 정정 A를 폄하하지 않고, 구도·브랜드 밀착 때문에 B 선택
더 많은 우주 모션이 필요하다 정적 결함을 회전으로 강조할 뿐이라는 모션 담당 반박 행성 위치·각도 고정, 재질 220ms·앞 고리 40+180ms

형태 담당은 2차 실렌더 후 A에서 B로 의견을 수정했다. 구도 담당은 B를 유지하면서 구체 곡률 복원을 요구했다. 종합 담당은 다수결 대신 보호 ROI와 실제 225px 형태를 근거로 수정 B를 선택했다. 리드는 마지막 마스크 분리 후 실제 배경 전용 ROI를 다시 검증했다.

최종 판정 기준

시간·날짜·브랜드의 보호 배경 ROI 변화는 0이어야 한다. 구면 명암·그림자·앞 고리의 폭이 225px에서도 남아야 한다. AOD는 같은 곡률과 가림 관계를 유지하고 채운 재질을 숨겨야 한다. 행성은 회전·이동하지 않고 전체 360ms를 늘리지 않는다. 공식 드래곤 path·INFINITY·시각 위치는 그대로 유지한다.

최종 선택은 B의 관측창 구도 + A의 구면/고리 재질 원리다. 이 판단은 사용자 조사나 객관적 최고 점수라는 주장이 아니다. 실제 워치에서 B가 어두운 패널로만 보이면 A 대안으로 돌아가거나 몸체 광원을 재조정해야 한다.
