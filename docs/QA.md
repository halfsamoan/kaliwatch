## 픽셀 비교의 범위와 남은 차이

**다이얼 정보 영역 반경 220px 내부는 전환 종료와 정적 기준의 픽셀 차이가 0이다.** 유동 크기 448×448 캡처의 CSS 원형 클립 경계·바깥에서는 269픽셀, 최대 RGB9의 미세한 AA 차이가 남는다. DOM·computed 속성·최종 모션은 같다. 이를 해결했다고 주장하거나 전체 이미지가 완전히 같다고 표현하지 않는다. 근거는 `evidence-v4/transition-pixel-comparison.json`과 독립 최종 검증이다.

초기 전체 이미지 assertion은 `Error: Completed active transition pixels match static renderer`로 실패했다. 차이 위치를 분리해 정보 영역과 CSS 호스트 경계를 따로 기록하도록 검수를 수정했다. 격리·overflow·효과 cleanup 실험은 이 차이를 없애지 못했고, 불필요한 변경을 최종에 남기지 않았다.

천체 보호 ROI를 전체 글자 포함 화면에서 비교하면, mask subtree를 제거한 뒤 글꼴 AA가 달라지는 혼동도 있었다. 실패 출력은 `Error: Planetary decoration changes zero pixels in time reading ROI`, 변화 1,171픽셀/max7로 실제 숫자 가장자리에 한정됐다. 최종 ROI 검사는 읽는 전경을 제외한 **천체 배경 자체**를 비교하며, 글자의 위치·노드·전환은 별도 검증한다. 진단 PNG도 보존했다. 초기 후보 B의 max137 침범과 이 AA 현상을 같은 문제로 취급하지 않는다.

900px PNG를 450px로 샘플링해 원형 영역 159,068픽셀 중 비영 RGB 17,999픽셀, **11.3153%**를 얻었다. 별도 후보의 직접 450px 렌더 수치와 방법이 달라 혼용하지 않는다. 15% 디자인 참고값 아래지만 실제 패널 소비전력·번인·공식 WFF 메모리 검사·심사 통과를 뜻하지 않는다.

## 미확인

실제 워치의 야외 가독성·밝기·전력·번인·터치·메모리·프레임 속도, APK/WFF XML·공식 validator는 미확인 또는 미수행이다. 브라우저에서의 gradient·mask가 WFF에 그대로 이식된다고 가정하지 않는다. AOD 벡터와 Active 재질을 분리해 재구현·자원 검증해야 한다.
