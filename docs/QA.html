픽셀 비교의 범위와 남은 차이

다이얼 정보 영역 반경 220px 내부는 전환 종료와 정적 기준의 픽셀 차이가 0이다. 유동 크기 448×448 캡처의 CSS 원형 클립 경계·바깥에서는 269픽셀, 최대 RGB9의 미세한 AA 차이가 남는다. DOM·computed 속성·최종 모션은 같다. 이를 해결했다고 주장하거나 전체 이미지가 완전히 같다고 표현하지 않는다. 근거는 evidence-v4/transition-pixel-comparison.json과 독립 최종 검증이다.

초기 전체 이미지 assertion은 Error: Completed active transition pixels match static renderer로 실패했다. 차이 위치를 분리해 정보 영역과 CSS 호스트 경계를 따로 기록하도록 검수를 수정했다. 격리·overflow·효과 cleanup 실험은 이 차이를 없애지 못했고, 불필요한 변경을 최종에 남기지 않았다.

천체 보호 ROI를 전체 글자 포함 화면에서 비교하면, mask subtree를 제거한 뒤 글꼴 AA가 달라지는 혼동도 있었다. 실패 출력은 Error: Planetary decoration changes zero pixels in time reading ROI, 변화 1,171픽셀/max7로 실제 숫자 가장자리에 한정됐다. 최종 ROI 검사는 읽는 전경을 제외한 천체 배경 자체를 비교하며, 글자의 위치·노드·전환은 별도 검증한다. 진단 PNG도 보존했다. 초기 후보 B의 max137 침범과 이 AA 현상을 같은 문제로 취급하지 않는다.
