# Orbital Observatory v4 — 드래곤과 우주 관측창

버전 4.0.0 / 2026-10-25. 이번 결과물은 원형 Galaxy Watch용 **브라우저 디자인 시스템**이며 APK·WFF 구현이 아니다. v1·v2·v3는 상위 폴더의 각 ZIP에 보존했다.

## v4 현재 계약 — Orbital Observatory

7인 토론의 결론과 반박은 `DEBATE.html`에 있다. 작은 초승달·타원 아이콘을 폐기하고, 우측 화면 밖의 큰 구체를 일부만 보는 구도로 바꿨다. 아래 v3/v2 항목은 계승한 시스템의 이력이며, 충돌 시 이 v4 계약을 따른다.

- 원자료 `celestial.js`: 중심 `(458,102)`, r126, 기울기 -26°. 실제 천체 시뮬레이션이 아닌 독자 SVG.
- 정적 레이어: 뒤 링 → 구면 광원·대기 띠·그림자 → 앞 링. 3개 주 면 띠와 분리 틈, 18개 미세 선.
- 구체·림 mask는 x320→338, 고리는 x345→372로 각각 감쇠한다. 재질 .59. 전체를 어둡게 해 곡률까지 지우지 않는다.
- Active 재질 220ms, 앞 고리 40ms 지연+180ms. 행성의 위치·기울기 고정, 추가 회전·비행·무한 반짝임 없음.
- AOD 몸체는 opaque black으로 뒤 링을 가린다. stroke만 .45. 같은 곡률의 림·앞 고리는 남기고 채운 재질을 숨긴다.
- 시간·날짜·브랜드의 보호 배경 ROI는 장식 변화 0. 구체 상반구 2,531픽셀에서 뒤 링 제거 전후 변화 0.
- 공식 드래곤 path, INFINITY, 숫자 기준선, 기존 360ms 궤도 정렬·Live tick·중간 반전·저감 모션은 유지한다.
- 최종 AOD 비영 RGB는 같은 900→450 샘플링으로 약11.32%. 실제 전력·WFF 지원 검증이 아니다.

`celestial-active`, `celestial-ambient`, `celestial-front-light`는 공통 DOM에서 opacity를 전환한다. SVG gradient·mask는 브라우저의 재질 표현이며 WFF 지원으로 과장하지 않는다. 이식 시 Active 재질 자산과 AOD 벡터를 분리해 재구현하고 공식 자원·메모리 검사를 수행한다. 원형 CSS 호스트 경계의 미세 AA 차이는 QA에 남겼다.

## 계승 이력: v3 — Cosmic / INFINITY

공식 드래곤과 초록색 위계는 유지한다. 바깥 여백에 고정된 별 20개, 작은 십자 별빛 2개, 어두운 청록색 고리 행성을 배치했다. 실제 천문 데이터나 별자리 지도가 아닌 독자 장식이다. 새 반복 모션은 없고 Active와 AOD에서 같은 형태를 유지한다. `starlight #8CA6B5`, `celestialRim #506E7B`, `celestialShade #081419`는 주변 장식에만 사용한다.

Active 하단은 `kali@orbit:~$ INFINITY`, AOD의 하단 서명도 `INFINITY`다. 시간·공식 드래곤·360ms 복귀 구조는 유지했다. v1·v2 ZIP은 상위 outputs 폴더에 보존했다.

## 기존 v2에서 이어받은 디자인 결정

사용자 요청에 따라 임의로 그렸던 작은 용을 없애고 **Kali 공식 Press Pack의 실제 드래곤**을 사용한다. AOD에도 같은 드래곤과 윤곽형 시각, 정지된 분절 궤도를 남긴다. Active 복귀에서는 화면을 새로 끼워 넣지 않고 같은 시각·드래곤 노드가 그 자리에서 밝아진다. 궤도가 14도 정렬되며 상태값이 뒤따른다.

시간은 처음부터 읽을 수 있다. 시·분을 이동·확대·축소하지 않는다. AOD에서 초 마커·걸음 수·게이지·프롬프트는 비표시하며, 반복 스캔이나 무한 맥동은 없다.

## 모션 명세

기본 곡선 `cubic-bezier(.22,1,.36,1)`. AOD→Active는 최대 **360ms**, 반대 방향은 **180ms**다.

| 대상 | AOD → Active | Active → AOD |
|---|---|---|
| 시·분 | fill과 stroke-opacity 220ms. 같은 문자·좌표·크기 유지 | 180ms에 어두운 안쪽과 윤곽 복귀 |
| 드래곤 | color·opacity 280ms, 공간 이동 없음 | 180ms, 낮은 밝기의 같은 실루엣 |
| Active 궤도 | opacity + rotate(-14°→0°), 360ms | 현재 opacity에서 180ms에 비표시 |
| 분절 AOD 궤도 | 220ms에 비표시 | 180ms에 표시 |
| 상태값·게이지 | 80ms 지연 + 220ms opacity | 180ms에 비표시 |
| AOD 배터리 | 120ms에 비표시 | 180ms에 표시 |
| 날짜·브랜드 | 같은 위치에서 색·밝기만 전환 | 같은 위치에서 색·밝기만 전환 |

360ms는 원주 방향을 따라 정렬되는 시그니처 전환에 한정한다. 버튼 반응이나 시간 읽기를 기다리게 하는 지연이 아니다. 공간 이동은 궤도만 맡는다. 색·fill·stroke-opacity는 실제 브라우저 페인트를 발생시킬 수 있으므로 모든 효과가 GPU 합성만으로 작동한다고 주장하지 않는다. 실기 성능은 따로 확인한다.

레이어는 사라진 최종 상태에 `opacity=0`, `visibility=hidden`을 함께 둔다. 전환 중에만 WAAPI가 visibility를 visible로 유지하고, 끝나면 기본 속성으로 복귀한다. 잔여 모션·숨겨진 정보가 남지 않게 한다.

## 중단·반전·갱신 정책

- **중간 반전:** 현재 computed opacity·색·transform을 먼저 읽고 기존 효과를 취소한다. 같은 SVG 노드의 목표 속성을 바꾼 뒤 현재값에서 새 상태로 이어간다.
- **현재 시각 갱신:** 노드를 교체하지 않고 바뀐 속성과 글자만 갱신한다. 1초 경계가 지나도 진행 중 전환을 취소하지 않는다.
- **AOD:** 현재 시각 모드에서만 분 경계 갱신. 초·모션 반복 없음.
- **저감 모션:** 수동 OR OS 설정. 즉시 최종 상태, 이동·색 전환·지연 없음. OS 선호를 수동 off로 무시할 수 없다.
- **재생 버튼:** 먼저 AOD를 보여준 뒤 140ms 후 Active로 복귀시킨다. 실제 전환 부분은 360ms다. 상태 버튼·저감 모션·새 재생·렌더링 조작으로 남은 예약을 취소한다.
- **10% 검토:** 디자인 모션 시간과 지연을 10배로 늘린다. 실제 배포 기본값이 아니다.
- **화면 밖 / 창 숨김:** 효과·예약·시계 타이머를 멈춘다. 현재 시각 모드에서 다시 보이면 시간을 다시 읽는다.

## WFF v4 추후 적용

현재 폴더에는 APK나 WFF XML이 없다. 브라우저 JS를 WFF 안에 넣지 않는다.

1. 기존 KALIWATCH의 변경 내용을 보존하고 새 테마나 별도 빌드 변형으로 추가한다. 원래 Terminal Green을 덮어쓰지 않는다.
2. 450 설계 좌표를 WFF로 매핑한다. 시간은 정적 PNG 대신 `DigitalClock/TimeText`로 만들며 실제 시간대·포맷을 따른다.
3. 공식 드래곤의 원형상을 리소스화한다. path를 임의의 용으로 대체하지 않는다. 출처와 브랜드 표시를 유지한다.
4. AOD·Active 공통 위치를 유지한다. AOD에서 선택 정보와 초를 비표시한다. `Variant`와 지원 속성으로 설계의 시각 의도를 재현한다.
5. WFF Variant duration은 전환 시간의 비율이다. 이 문서의 360ms나 CSS 키프레임 값을 그대로 넣지 않는다. WFF v4가 각 속성·연출을 지원하는지 확인하고 필요하면 더 단순한 도형 전환으로 매핑한다.
6. 배터리·걸음 수는 가용한 실제 데이터·컴플리케이션·권한에 연결한다. 제공되지 않으면 `—`. 시연 값을 실데이터처럼 배포하지 않는다.
7. 공식 WFF validator·메모리 검사·Gradle 빌드·에뮬레이터를 실행한다. 그 뒤 실제 워치에서 AOD↔Active 반복·손목 깨우기·밝기·번인 보호·24시간 전력을 검증한다.

## 검증 경계

AOD 래스터 발광 비율 약 11.46%는 이미지 분석값이다. 실제 소비전력·번인·프레임 속도·스토어 적합성을 증명하지 않는다. 터치·베젤·건강 데이터·12시간제·다국어 날짜·컴플리케이션 편집은 후속 구현이다. 상세 근거는 `QA.md`와 `REFERENCES.md`에 있다.
