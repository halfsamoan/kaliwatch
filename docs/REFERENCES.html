v4 추가 — 형태와 토론

현재 행성은 celestial.js의 독자 구면·띠·그림자·앞뒤 링이다. NASA/JPL Shadow and Shade와 NASA Rings and Shadows는 형태 설계자가 직접 검색·열람한 원자료다. 구면 명암·고리 가림·폭이 다른 띠를 이해하는 근거로 사용했으며 사진 자산을 복사하지 않았다. 조명·색·좌표·모션은 디자인 판단이다.

7역할의 제안과 실제 반박·측정·재반박은 DEBATE.html에 기록했다. 숫자 다수결이나 가짜 전원 승인이 아니라 보호 ROI·225px 렌더·AOD 가림을 근거로 구도를 선택했다. 이번 최종 수치는 QA와 evidence-v4를 기준으로 하며 아래는 버전별 이력이다.

v3 추가 — Cosmic / INFINITY

사용자 요청에 따라 별빛·고리 행성을 SVG 도형으로 소량 추가하고, Active와 AOD의 서명을 INFINITY로 바꿨다. 실제 별자리·관측 정보가 아닌 독자 장식이므로 천문 데이터 출처를 꾸미지 않는다. 공식 Kali 드래곤의 path는 바꾸지 않았다.

v2 추가 — 실제 Kali 드래곤과 AOD 복귀

사용자의 추가 요청으로 v1의 자체 제작 용은 제거했다. 현재 결과물은 Kali 공식 Press Pack의 드래곤 원본을 사용한다. 원본 path 좌표를 그대로 유지하고 fill만 currentColor로 바꿨다. 고정 commit·바이트·SHA-256은 ../brand/PROVENANCE.md에 있다.

공식 자산을 가져온 뒤 화면·7개 SVG의 path d를 원본과 비교했다. 임의로 생성한 드래곤이나 제3자 재해석 로고가 아니다. Kali 상표 정책과 출처를 함께 남기며 공식 제품·승인을 주장하지 않는다.

AOD의 윤곽 숫자·분절 궤도·드래곤 점등 순서는 이번 디자인 판단이다. AOD에도 실제 드래곤을 남기고, 같은 SVG 노드가 Active로 이어지는 360ms 브라우저 전환으로 구성했다. 기존 v1의 AOD에서 드래곤을 제외했던 결정은 v2에서 대체됐다. 현재 상세 명세는 DESIGN-SYSTEM.md, 검수는 QA.md를 기준으로 한다.

직접 검색한 공식 레퍼런스

시각 원리

Ressence TYPE 3 공식 소개는 읽기 쉬운 평면적 표시, 회전 디스크, Eucalyptus 녹색을 설명한다. 여기서 시간을 읽는 중심 정보와 주변 움직임의 위계를 참고했다. Phosphor Orbit은 큰 고정 디지털 시간과 단일 궤도로 새로 구성한다. 레퍼런스의 다이얼 배치·바늘·브랜드 표시·제품 이미지를 결과물에 복제하지 않았다.

CMF Watch Pro 2 공식 제품 페이지도 검색·열람했다. 제품 자체의 원형 시계 맥락을 보조 비교 대상으로만 사용했다. 지역별 페이지와 검색 색인 내용이 달라 동적 워치페이스·AOD 기능에 관한 기술 근거로 사용하지 않는다.

나중에 적용할 때의 기술 근거

  • Google · WFF ambient 요구사항: interactive와 ambient 외형을 분리하고 essential 정보와 발광 면적을 줄이도록 안내한다. 문서는 AOD의 15% 기준을 연결한다. 이 패키지가 기기·스토어 심사 기준을 통과했다는 주장은 하지 않는다. 실제 렌더와 공식 도구로 다시 확인해야 한다.
  • Google · WFF 설정과 좌표계: WFF의 width·height는 기기에 맞게 확대되는 좌표 범위이며 물리 픽셀이 아니다. 이번 SVG의 450×450도 정규 설계 좌표다. 브라우저 JavaScript는 WFF의 실행 코드가 될 수 없으므로 별도 이식이 필요하다.
  • Google · WFF v4 전환 소개: ambient 진입·이탈 전환을 설명한다. 브라우저의 모션을 동일하게 지원한다고 가정하지 않고 대상 버전의 Variant·리소스로 매핑할 때 재확인한다.
  • Google · WFF 메모리 사용량: ambient 10MB, interactive 100MB 메모리 한도와 리소스 계산을 설명한다. SVG 파일 크기나 브라우저 메모리만으로 이 조건을 충족했다고 판단하지 않는다.

적용 판단과 한계

메인 디자인 판단: Phosphor Orbit은 Kali 초록색, archsport의 정보 위계, 사용자 레이더·신호처리 맥락을 통합한 새 방향이다. 특정 제품의 완성된 화면을 따라 만든 디자인이 아니다.

  • Active, AOD, reduced-motion 상태를 한 시스템으로 다룬다. reduced motion은 정보가 아니라 장식 움직임을 줄인다.
  • 큰 시간은 읽는 동안 움직이거나 찌그러지지 않게 유지한다. 주변 단일 궤도가 시그니처를 맡는다.
  • 브라우저에 표시하는 배터리·걸음·시간 프리셋은 시연 데이터다. 실기기 센서 값으로 가장하지 않는다.
  • 450 정규좌표 프리뷰는 배치 검토용이다. 실제 워치의 표시 크기·밝기·알림 여백·폰트 렌더·번인·배터리 소모·프레임률은 미확인이다.
  • 나중에 기기를 확보하면 대상 모델·Wear OS/WFF 버전을 확인하고 리소스 변환, 공식 XML·메모리 검사, 실제 active↔AOD 전환 및 가독성 검수를 진행한다.

원본 KALIWATCH와 archsport 저장소는 이 조사 과정에서 변경하지 않았다. 커밋·푸시·외부 게시도 하지 않았다.
